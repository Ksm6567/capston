# Capstone EDR

Windows 환경에서 실시간 위협 탐지, YARA 스캔, 행위 기반 탐지, 인시던트 대응, 로그/보고서 관리를 수행하는 EDR 보안 대시보드입니다.

## 주요 기능

- 회원가입 및 로그인 기반 사용자 인증
- 모든 회원가입 사용자가 앱 내부 관리자 기능 사용 가능
- Sysmon 이벤트 로그 기반 실시간 행위 탐지
- Sysmon을 사용할 수 없을 때 프로세스 스냅샷 기반 제한 탐지 지원
- YARA 실시간 감시 및 정밀 스캔 지원
- 탐지된 위협을 인시던트 카드로 표시
- 위험도, 프로세스 정보, 파일 경로, 탐지 룰, 대응 상태 확인
- 인시던트 대응 기능
  - 탐지 파일 폴더 열기
  - 탐지 파일 격리
  - 의심 프로세스 종료
  - 유지 관찰 처리
- 사용자별 Wazuh/행위 탐지, YARA, 대응 로그 저장
- 날짜/엔진/사용자 기준 보고서 조회
- 설정 페이지에서 계정 정보, 알림, 자동 대응 정책, 사용자 관리 제공
- 안전한 테스트용 인시던트 생성 API 및 테스트 스크립트 포함

## 최근 변경 사항

- 기본 `admin` 계정뿐 아니라 회원가입한 모든 사용자가 앱 관리자 권한을 사용하도록 변경했습니다.
- 위협 탐지 인시던트 카드에서 `프로세스 종료` 대응 기능을 사용할 수 있도록 복구했습니다.
- 위협 탐지 인시던트 카드의 `IP 차단` 버튼은 숨김 처리했습니다.
- 설정 화면의 자동 대응 정책에서 `의심 IP 자동 차단` 항목을 제거했습니다.
- 알림 설정에서 `브라우저 데스크톱 알림` 항목과 실행 로직을 제거했습니다.
- 실시간 탐지 엔진 시작 시 cmd/PowerShell 창이 반복적으로 켜졌다 꺼지는 문제를 수정했습니다.
  - 원인은 행위 탐지 모듈이 `wevtutil.exe`, `powershell.exe`를 반복 실행하면서 창 숨김 옵션을 사용하지 않았기 때문입니다.
  - 해당 보조 명령들이 Windows에서 창 없이 백그라운드로 실행되도록 수정했습니다.
- 백엔드의 상태 조회 및 대응 명령 실행도 숨김 실행 방식으로 정리했습니다.

## 탐지 엔진

### 행위 기반 탐지

행위 탐지 엔진은 `backend/src/behavior_monitor.py`에 구현되어 있습니다.

Sysmon이 설치되어 있고 이벤트 로그를 읽을 수 있으면 다음 로그를 기반으로 탐지합니다.

```text
Microsoft-Windows-Sysmon/Operational
```

Sysmon을 사용할 수 없거나 이벤트 로그 접근이 불가능하면 프로세스 스냅샷 모드로 전환하여 실행 중인 프로세스를 주기적으로 확인합니다.

탐지 가능한 주요 행위는 다음과 같습니다.

- 의심스러운 PowerShell 실행
- 반복적인 셸 실행
- 랜섬웨어 유형의 복구 방해 명령
- LOLBin 기반 의심 실행
- Sysmon 이벤트 기반 네트워크, 프로세스, 파일, 레지스트리 행위

### YARA 탐지

YARA 탐지 엔진은 `backend/src/yara_scanner.py`에 구현되어 있습니다.

지원하는 스캔 방식은 다음과 같습니다.

- 실시간 파일 감시
- 정밀 스캔
- 로컬 핵심 룰 기반 탐지
- 외부 확장 룰 기반 탐지

YARA 룰에 매칭된 파일은 인시던트로 변환되어 위협 탐지 화면에 표시됩니다.

## 인시던트 대응

위협 탐지 화면에서 인시던트별로 다음 대응을 수행할 수 있습니다.

- `폴더 열기`: 탐지된 파일이 위치한 폴더를 엽니다.
- `파일 격리`: 탐지된 파일을 사용자별 격리 폴더로 이동합니다.
- `프로세스 종료`: 탐지 이벤트에 포함된 의심 프로세스 트리를 종료합니다.
- `유지 관찰`: 인시던트를 관찰 대상으로 표시합니다.

일부 대응 기능은 Windows 운영체제 권한에 따라 관리자 승인 창이 표시될 수 있습니다.

## 자동 대응 정책

현재 설정 화면에서 지원하는 자동 대응 정책은 다음과 같습니다.

- Critical 탐지 자동 파일 격리
- 의심 프로세스 자동 종료

`의심 IP 자동 차단` 기능은 설정 화면에서 제거되었고 기본적으로 비활성화됩니다.

## 인증 및 권한

앱은 `X-Session-Token` 헤더를 사용하는 세션 기반 인증을 사용합니다.

기본 관리자 계정은 다음과 같습니다.

```text
아이디: admin
비밀번호: admin1234
```

현재는 회원가입한 모든 사용자가 앱 내부 관리자 권한을 갖습니다. 따라서 일반 회원가입 계정도 설정, 실시간 탐지, 보고서, 파일 격리, 프로세스 종료 등의 기능을 사용할 수 있습니다.

단, 앱 관리자 권한과 Windows 운영체제 관리자 권한은 다릅니다. 프로세스 종료, Sysmon 설치, 보호된 경로 접근 등은 Windows 관리자 승인이 추가로 필요할 수 있습니다.

## 요구 사항

Python 패키지는 `backend/requirements.txt`에 정의되어 있습니다.

```text
yara-python==4.5.1
fastapi
uvicorn
websockets
sqlalchemy
```

전체 기능을 사용하려면 Windows 환경을 권장합니다. Sysmon, `wevtutil.exe`, `taskkill.exe`, Windows 이벤트 로그를 사용하는 기능이 포함되어 있기 때문입니다.

## 실행 방법

의존성 설치:

```bash
pip install -r backend/requirements.txt
```

서버 실행:

```bash
python backend/main.py
```

브라우저에서 접속:

```text
http://127.0.0.1:8000
```

로컬 실행 또는 패키징 환경에서는 `launcher.py`를 사용할 수도 있습니다.

## 빌드

Windows 실행 파일 빌드를 위한 스크립트가 포함되어 있습니다.

```text
build_exe.ps1
```

로컬 Python 환경과 의존성 설치가 완료된 뒤 실행 파일 빌드에 사용할 수 있습니다.

## 참고 사항

- Sysmon을 설치하면 행위 탐지 정확도가 높아집니다.
- Sysmon이 없더라도 제한적인 프로세스 스냅샷 모드로 탐지가 가능합니다.
- 로그와 인시던트는 사용자별로 저장됩니다.
- 격리된 파일은 `quarantine/` 디렉터리에 저장됩니다.
- 외부 YARA 룰은 `backend/rules/` 하위 스크립트를 통해 별도로 동기화할 수 있습니다.
